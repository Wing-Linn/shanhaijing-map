# 山海经 · 3D 山岳图

> 以三维青绿山水之法，再现《山海经》中名山异物。

[![Open in Bolt](https://bolt.new/static/open-in-bolt.svg)](https://bolt.new/~/sb1-ynjypntb)

## 项目简介

本项目基于中国古代地理志怪典籍《山海经》，构建了一个可交互的三维山岳地图。以青绿山水画为视觉灵感，将南山经、西山经、北山经、东山经、中山经五方山系中的二十四座名山——招摇之山、青丘之山、昆仑之丘、发鸠之山、太华之山等——以翠玉层峦、金光云雾之态呈现于画绢之上。

用户可旋转视角俯览天下，点选山岳以阅其记载：山中所产金玉、所出河流，以及九尾狐、精卫、烛龙、西王母、凤凰、刑天、夸父等神灵异兽之状与功效。

## 技术栈

- **React 18** + **TypeScript** — 前端框架与类型系统
- **Three.js** — WebGL 三维场景渲染（山体建模、云雾粒子、光照、动画）
- **Tailwind CSS** — 样式系统
- **Vite** — 开发与构建工具
- **lucide-react** — 图标库
- **Noto Serif SC / Noto Sans SC** — 思源宋体与黑体，营造古典书卷气韵

## 功能特性

### 三维山岳地图
- 二十四座名山以多层翠玉色锥体堆叠而成，模拟青绿山水画中层峦叠嶂之态
- 金色光柱自峰顶升起，光球悬浮脉动，如仙山灵气
- 十八朵白云飘浮于山间各层，缓缓漂移，营造仙气缭绕之感
- 天际悬金日一轮，光晕柔和；地面有雾色湖泊居中
- 暖金主光、翠绿补光、金边逆光三光源照明，再现绢本设色之感

### 交互探索
- **拖拽旋转** — 鼠标拖动可三百六十度环览全景
- **滚轮缩放** — 拉近细观单山，推远纵览天下
- **点击山岳** — 选中某山后镜头自动聚焦，右侧展开详情面板
- **悬停高亮** — 鼠标悬于山岳之上时山体微微发光放大

### 搜索与筛选
- 按山名、异兽名、记载内容全文搜索
- 按五方山经（南、西、北、东、中）分类筛选
- 左侧列表实时联动，显示每山所载异物数量

### 详情面板
- 山经原文记载
- 水系标签（河流名）
- 所产珍材标签（金、玉、青雘等）
- 异物志卡片：异兽、神鸟、怪鱼、异蛇、神草、神灵六类，各以色区分，附形态描述与功效

## 数据来源

山岳、河流、异物数据整理自《山海经》原文，涵盖南山经、西山经、北山经、东山经、中山经及海内、海外、大荒各经。每座山岳的描述、所产、水系及关联异物均依据原典整理。

## 设计理念

视觉风格取法中国青绿山水画传统——以石青、石绿为主色，金碧点缀，设色于绢帛之上。界面以米黄仿古绢底为背景，墨绿与赭金为文字主色，思源宋体书写山名经文，力求再现古卷气韵。三维场景中以暖光金日、翠峦云雾构建仙山意境，使观者如临帝之下都，游于山海之间。
